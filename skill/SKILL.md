# AI Art Video Studio
Ask for duration, voice on/off, user's script or topic, art style, language and loop on/off. Preserve user scripts. Generate scene descriptions if no script is supplied. Verify renderer and narration tools before claiming successful video creation. The local starter produces illustrated slides, not generative AI images or motion video. Use app/main.py for the preview and integrate model backends for actual AI generation.
