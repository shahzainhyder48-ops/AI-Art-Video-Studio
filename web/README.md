# Browser-based starter

Open `index.html` directly in a browser to test the video scene planning form. This static site works without a server. It **does not** generate actual images, narration or MP4 files. Downloaded JSON plans can be used as inputs to a future backend. To publish later, host the `web/` folder on a static hosting service or use GitHub Pages configured for the `/web` folder via a deployment workflow. Never put private API keys in frontend JavaScript.
